# ⚡ Fable 5 Prompt Forge

A single-file, zero-dependency prompt library built for **Claude Fable 5**. Open
[`index.html`](./index.html) in any browser — or paste its contents into Claude as
an artifact — and start forging.

## What's inside

- **📚 Curated library** — 50+ hand-engineered *single-shot* prompts across nine
  categories (games, simulations, generative art, sound, explorables, micro-tools,
  AI tooling, weird experiments, learning & story). Each prompt is designed so that
  one paste into Claude yields one complete, publishable, self-contained HTML
  artifact: no build step, no external assets, no placeholders.
- **🎰 Goal Prompt Machine** — a slot-machine generator that assembles coherent
  prompts from five reels (format × subject × mechanic × aesthetic × twist).
  The reels multiply into **1.5+ million unique prompts**, comfortably clearing the
  4,000-prompt goal.
- **🔥 Forge meter** — every copy or spin counts toward a persistent 4,000-prompt
  goal tracked in `localStorage`.

## How to use a prompt

1. Click **Copy** on any card (or spin the Machine and copy the result).
2. Paste it into Claude with no extra context.
3. Save the returned artifact as `index.html` and publish it anywhere static —
   GitHub Pages, CodePen, itch.io, Netlify drop.

## Why these prompts work

Every prompt bakes in the four ingredients of a reliable single-shot:

1. **A vivid concept** — so the model commits to one strong direction.
2. **Hard constraints** — single file, no libraries, no TODOs.
3. **A polish bar** — title screen, 60fps motion, juicy feedback.
4. **One surprising twist** — the detail that makes people share it.

## Remixing

Prompts are starting points. Copy two cards and ask Claude to fuse them, or append
your own twist: *"…but make it multiplayer on one keyboard."* Lock reels on the
Machine to iterate around an idea you like.
