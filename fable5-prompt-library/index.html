What is this?

A self-contained prompt library built for Claude Fable 5. Every prompt is single-shot: one paste, one complete artifact out — a game, simulation, tool, or toy in a single HTML file with no build step and no external assets. Perfect for quick publishing to GitHub Pages, CodePen, or itch.io.

How to use a prompt

1. Hit Copy on any card (or spin the Machine).
2. Paste it into Claude — no extra context needed.
3. Claude returns a finished artifact. Save it as index.html and publish.

Why these prompts work

Each one bakes in the four ingredients of a great single-shot prompt: a vivid concept (so the model commits to a direction), hard constraints (single file, no assets, no placeholders), a polish bar (juice, feedback, a title screen), and one surprising twist (the detail that makes people share it).

The 4,000 goal

The forge meter tracks every prompt you copy or spin, persisted in your browser. The curated library seeds the collection; the Goal Prompt Machine guarantees the supply never runs out — its slot reels multiply into millions of unique, coherent prompts.

Remixing

Stack prompts: copy two cards and ask Claude to fuse them. Or paste a card and add "…but make it multiplayer on one keyboard". The prompts are starting points — the forge rewards mutation.
